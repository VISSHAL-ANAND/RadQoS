# Publication Readiness Checklist

Last reconciled: 2026-10-29 UTC

## Venue and template

- [ ] Select the target IEEE conference or journal.
- [ ] Verify scope, submission deadline, official template, page limit, reference style, and supplemental-material policy from the venue's current instructions.
- [ ] Use the uploaded `IEEEpaper.pdf` as a visual reference only; do not copy its text, results, or subject matter.
- [ ] Do not force the paper into the example's six-page length if this would omit required methodology or evidence.

## Scientific integrity

- [ ] Primary 138-image benchmark is complete and validated, or study scope is explicitly revised.
- [ ] Every reported number is traceable to a run output.
- [ ] All tables and plots are generated from validated data, not manually invented.
- [ ] Abstract, results, discussion, and conclusion use the same locked results version.
- [ ] Dataset bit-depth discrepancy is described accurately.
- [ ] Simulated network results are clearly labelled as simulation.
- [ ] P2 is described as a custom base-plus-residual representation, not progressive JPEG 2000.
- [ ] Clinical safety and diagnostic-accuracy claims are not made without appropriate validation.
- [ ] Limitations, infeasible constraints, fallbacks, and negative findings are reported.
- [ ] Novelty claims are supported by a verified related-work review.

## References and attribution

- [ ] Verify every reference's authors, title, venue, year, volume/issue/pages, and DOI against a primary source.
- [ ] Confirm citations support the specific claims made.
- [ ] Review the NLM dataset terms and mirror license metadata.
- [ ] Cite the dataset and annotations appropriately.
- [ ] Avoid copying prose from sources or the supplied example PDF.

## Authors and declarations

- [ ] Confirm author names exactly as they should appear.
- [ ] Confirm affiliations, institutional emails, and corresponding author.
- [ ] Confirm funding and acknowledgement statements.
- [ ] Confirm conflicts of interest.
- [ ] Verify institutional ethics wording for secondary analysis of a public, de-identified dataset; do not invent an approval or exemption.

## Document quality

- [ ] Update the existing Library draft rather than recreating from scratch.
- [ ] Apply the official target-venue template.
- [ ] Check equations, symbols, tables, figures, captions, references, and column breaks.
- [ ] Export DOCX to PDF and inspect every page for clipping, overflow, unreadable figures, and font/rendering issues.
- [ ] Verify page count against the venue limit.
- [ ] Run a suitable similarity checker and record the actual tool and score. A below-20% score is a target, not a guarantee or a substitute for correct attribution.
- [ ] Archive final DOCX/PDF, source document if available, figures, raw outputs, metadata, logs, and exact code revision.

## Submission gate

Do not call the manuscript submission-ready until the scientific evidence is validated, references and claims are checked, venue rules are met, author/declaration details are confirmed, and the final exported PDF has been inspected.
